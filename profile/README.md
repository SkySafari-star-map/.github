# SkySafari - Professional Planetarium for Astronomy

## About SkySafari

SkySafari is a professional planetarium environment for exploring the night sky, identifying objects, and planning observation sessions. SkySafari brings together a detailed star map, telescope control, and a calm astronomy guide workflow so both beginners and experienced observers can move from curiosity to a clear view of the sky. Whether you are learning constellations for the first time or preparing a deep-sky session, SkySafari keeps the experience readable and focused.

SkySafari star map views help you see how the sky changes over time, while SkySafari telescope control connects your equipment to the same workspace. The result is a steady planetarium experience that supports learning, planning, and real observing without unnecessary clutter.
